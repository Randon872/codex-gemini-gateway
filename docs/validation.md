## 已解决的兼容问题

1. **工具重复**：历史 `additional_tools` 与当前工具定义拼接会产生重复命名空间。发给 Gemini 时优先使用当前完整工具集，保留消息、函数调用及结果。
2. **推理签名跨厂商不兼容**：Gemini 流中的 reasoning ID 加上来源前缀；切换时移除另一厂商的加密推理项。普通消息和工具结果继续保留。不会把 Google thought signature 当作 OpenAI encrypted reasoning。
3. **模型目录网络超时**：Codex 使用本机目录快照，避免启动时远程目录请求过慢；后续新增模型需刷新。
4. **重复 Accept-Encoding**：转发时移除客户端旧值，统一请求 identity，避免压缩 JSON 无法读取。
